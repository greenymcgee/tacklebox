# tacklebox

A set of tools and configurations I like to use.

## Packages

- [@tacklebox/next-eslint-config](./packages/next-eslint-config) - ESLint flat config for Next.js projects

## Installation

Install packages directly from GitHub:

```bash
# pnpm
npm install -D "github:greenymcgee/tacklebox#path:packages/next-eslint-config"

# pnpm
pnpm add -D "github:greenymcgee/tacklebox#path:packages/next-eslint-config"
```

## Development

This repo uses pnpm workspaces. To get started:

```bash
pnpm install
```
